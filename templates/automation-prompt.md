# 本地情报监控自动化提示词模板

## 用途

供 Codex 本地自动化调用已经实现的监控脚本。提示词不承担采集、精选和界面生成逻辑。

## 模板

```text
执行「<监控名称>」本地资讯监测。

运行 `<统一监控脚本绝对路径>`。脚本负责采集信息、按来源可信度和用户相关度筛选、与本地历史状态比较、去重，并调用 All Toast for Mac 展示结果。不要在自动化对话中重新生成或重复展示已经由浮窗展示的正文。

监控范围：
- 主题：<监控主题>
- 用户重点：<专业、产品、公司或关键词>
- 默认时间窗：<最近 24 小时>
- 补查范围：<漏跑时最大补查窗口>
- 来源优先级：<官方来源 > 权威来源 > 行业来源 > 社交平台线索>
- 社交平台内容只有经过权威来源交叉核实时才标记为“已核实”；否则标记为“待核实”。

解析脚本 JSON 状态：
- no_new、already_shown、rate_limited：保持静默。
- notified、shown：只简短确认，不重复浮窗正文。
- partial：简短说明暂时不可用的来源，其他检查继续有效。
- fetch_failed、render_missing、render_failed、invalid_output 或非零退出码：输出简短错误摘要和失败环节。

不发送飞书消息、邮件或其他外部通知，除非该监控的独立配置明确要求。
```

## 约束

- 自动化 prompt 只做调度和状态解释。
- 时间窗、来源、去重、精选与通知正文写进监控器配置或代码。
- 不在 prompt 中复制底层命令帮助、API 参数或整套业务规则。
- 私人来源、关键词和领域配置放在独立私有项目中，不写入通用框架或公开模板。
